# Portunus 전체 기능 안내

**접속부터 진단·조치·기록까지, IT 엔지니어의 작업을 한곳에서 이어갑니다.**

이 문서는 Portunus **1.4.0**에 구현된 기능을 기준으로 합니다. [다운로드·소개 화면](../README.md) · [전체 기능 소개 영상](https://github.com/bluewind201/Portunus/releases/download/v1.4.0/portunus-features-v1.4.mp4)

## 1. 원격 접속과 파일 전송

여러 접속 방식을 세션으로 정리하고, 같은 SSH 연결에서 터미널과 파일 작업을 이어갑니다.

| 기능 | 제공하는 작업 |
|---|---|
| SSH | 암호·개인 키·keyboard-interactive 인증, OTP 추가 인증, 첫 접속 호스트 키 확인 |
| 점프 호스트 | 저장된 SSH 세션을 경유하는 최대 4단계 연결, 단계별 호스트 키 확인 |
| SSH 터널 | 로컬→원격·원격→로컬 포트 포워딩. 수신 주소는 루프백으로 제한하고 SSH 종료 시 함께 정리 |
| Telnet·Raw TCP | 네트워크 장비 CLI 및 TCP 서비스에 접속 |
| 시리얼 콘솔 | COM 포트·통신 속도를 지정한 장비 콘솔, Break 신호 전송 |
| SFTP 파일 패널 | SSH 연결을 공유하는 탐색·드래그 업로드·다운로드·이름 변경·폴더 삭제·전송 진행률 |
| RDP | Windows 원격 데스크톱(mstsc)을 외부 창으로 실행. 화면 크기·전체 화면·다중 모니터·관리자 세션 옵션 |
| VNC | 앱 안 원격 화면, 창 맞춤·클립보드·Ctrl+Alt+Del |
| RustDesk | 클라이언트 실행 연동, IPv4/IPv6 직접 IP 접속 및 기존 ID 방식 세션 |
| 로컬 터미널 | PowerShell·PowerShell 7·명령 프롬프트·WSL을 탭으로 실행. 해당 셸은 PC에 설치되어 있어야 함 |

**강점:** 장비 CLI와 파일 전송을 별도 로그인 없이 이어가고, 점프 호스트와 터널로 내부망 작업 경로를 구성합니다. 레거시 SSH 호환은 필요한 세션에서 선택할 수 있습니다.

RustDesk는 상대 PC의 RustDesk 실행과 직접 IP 접속 허용이 필요합니다. 직접 IP 접속은 신뢰할 수 있는 LAN/VPN에서 사용하세요. RDP는 앱 안에 포함된 화면이 아니라 Windows 외부 창입니다.

## 2. 명령어를 찾고 입력하는 과정까지 돕는 터미널

- **입력 중 자동 완성:** 커서 위치의 단어에 맞춰 하위 명령·옵션·인수 후보와 설명·출처를 표시합니다. `Ctrl+Space`로 목록을 열고, `→`로 전체 후보, `Ctrl+→`로 한 단어를 넣습니다.
- **장비·모드별 안내:** Linux, Cisco/IOS형 EXEC·설정 모드, DB 클라이언트 문맥을 구분합니다. 장비 유형을 세션에서 직접 지정할 수 있습니다.
- **화면을 활용하는 후보:** 화면에 나온 인터페이스·VLAN·IP·파드·컨테이너·서비스 이름을 후보로 활용합니다.
- **다음 단계 안내:** `systemctl status nginx` 다음에 로그 확인을 제안하는 식으로 후속 점검 명령을 보여줍니다. Linux·Cisco·DB 절차와 사용자 정의 규칙을 지원하며 자동 실행하지 않습니다.
- **전체 화면 도구 안내:** vim의 일반·입력·비주얼 모드, less/man, top/htop, nano, `--More--` 상황에 맞는 단축키를 표시합니다.
- **위험 명령 확인:** 삭제·재부팅·디스크 초기화·위험한 DB 변경·Cisco 포트 종료 등 감지 규칙에 해당하면 대상과 내용을 실행 전에 확인합니다. 항상 확인·운영 세션만·확인 안 함을 설정할 수 있습니다.
- **스니펫·찾기·재연결:** 반복 명령 스니펫, 화면 검색, 선택 복사·우클릭 붙여넣기, 종료 후 재연결을 지원합니다.
- **명령 기록 선택:** 개인 명령 기억·추천은 기본 꺼짐입니다. 설정에서 켜거나 끄고 기록을 지울 수 있으며, 영구 기록은 금고 암호화를 사용합니다.
- **세션 로그:** 세션별·전체 로그, 시각 표시, 스크롤 화면 저장을 지원합니다.

**강점:** 명령을 외우는 부담을 줄이고, 대상 장비와 실행 내용을 확인하는 단계를 제공합니다. 위험 명령 감지는 알려진 규칙을 보조하는 기능으로 모든 오입력을 차단하는 것은 아닙니다.

## 3. 여러 장비를 함께 다루는 작업 공간

- 폴더 트리·그룹 색상·드래그 이동, 이름/IP/태그 검색, 최근 사용·즐겨찾기.
- 운영·스테이징·개발 환경 표시로 작업 대상 구분.
- 좌우·상하 2분할, 3분할, 4분할과 경계 크기 조절.
- 탭을 끌어 **단독 창으로 분리하고 다시 합치기**, 창 위치·크기 기억. SSH 연결과 화면 기록 유지.
- 여러 터미널에 **동시 입력**. 여러 줄 입력은 대상과 환경을 확인.
- **작업 세트:** 열린 세션·도구·분할 배치를 저장하고 다시 열기. 암호·실행 명령·도구 입력값은 세트에 저장하지 않음.
- 탭 넘김·열린 탭 목록·우클릭으로 다른 탭/오른쪽 탭/모든 탭 닫기.
- `Ctrl+K` 명령 팔레트, 도구 검색·분야별 분류, 가변 사이드바.

**강점:** 서버 로그와 네트워크 장비 CLI를 나란히 보고, 다중 모니터로 옮겼다가 같은 연결을 유지하며 다시 모을 수 있습니다.

## 4. 네트워크 검색·경로·서비스 진단

| 도구 | 제공하는 작업 | 활용 예 |
|---|---|---|
| IP 대역 검색 | CIDR 또는 시작/끝 IPv4, ICMP·TCP 응답, 열린 포트·지연, 필터·CSV·자산 등록. 한 번에 최대 65,536개 주소 | 정해진 대역의 응답 장비를 찾아 접속 자산으로 등록 |
| 경로 분석 | TTL 순서의 PC·응답 노드·무응답 홉·목적지 아이콘, 지연·응답 주소 후보·이전 측정 비교, 공인 IP WHOIS·origin ASN | 어느 홉 이후부터 응답이나 지연이 달라지는지 확인 |
| 핑 | 연속 응답 시간·손실·지터·그래프 | 간헐적 지연과 손실 관찰 |
| 경로 추적 | 목적지까지의 홉별 경로 | 기본 라우팅 경로 확인 |
| 포트 스캔 | TCP 서비스 포트 연결 확인 | 관리·서비스 포트 접근 여부 확인 |
| DNS 조회 | A·AAAA·MX·PTR·TXT 조회 | 정방향·역방향·메일·텍스트 레코드 점검 |
| 장비 통합 점검 | 서버·네트워크·보안 장비 프로필, DNS·사용자 지정 TCP 포트·HTTP·HTTPS 인증서 검사, 최대 20개 대상·JSON 보고서 | 여러 장비의 관리 접속과 인증서를 일괄 점검 |
| SNMP | v2c/v3 시스템 정보, 인터페이스 상태·속도·오류·초당 트래픽·사용률, OID walk·검색·CSV | 스위치 포트의 상태와 트래픽 확인 |
| 패킷 캡처·분석 | 패킷 목록·프로토콜 상세·바이트 화면, 표시 필터 문법 확인·적용, 캡처 파일 분석 | 실제 통신 내용과 프로토콜 문제 분석 |
| Nmap | 로컬 Nmap으로 상위 100개 TCP 포트 확인, 중지·결과 저장 | 서비스 노출 상태 확인 |
| 서브넷 계산기 | CIDR·와일드카드·서브넷 분할 | 주소 설계와 장비 설정 값 확인 |
| MAC 주소 변환 | Cisco·콜론·대시 형식 변환 | 장비별 MAC 표기 변환 |
| Wake-on-LAN | 매직 패킷 전송 | 지원 장비 원격 깨우기 |

**강점:** 검색 → 경로 확인 → 포트·인증서 점검 → 패킷 분석을 한 작업 공간에서 이어갑니다. IP 검색·통합 점검은 대상에 전용 에이전트를 설치하지 않습니다.

경로 분석은 관측한 TTL 홉을 보여줍니다. 실제 물리적 거리·장비 종류·모든 라우터 간 연결을 확정하지 않습니다. 무응답이 장비 부재를 뜻하지 않으며, Nmap은 완전한 취약점 진단 도구로 제공되는 기능이 아닙니다.

## 5. 서버·가상화·컨테이너 운영

| 도구 | 상태 확인 | 운영 작업 |
|---|---|---|
| Docker | 컨테이너·이미지·Compose 프로젝트, CPU·메모리·포트, 로그·inspect | 시작·중지·재시작·일시 정지·재개·삭제, 컨테이너 셸을 터미널 탭으로 열기 |
| Kubernetes | k8s·k3s·microk8s, 컨텍스트·네임스페이스, 노드·파드·디플로이먼트·서비스·인그레스·잡·이벤트 등, 사용량·로그·YAML·describe | 파드 셸, 롤아웃 재시작·복제 수 변경·파드 삭제. 사용자 지정 API 주소·포트와 원격 kubeconfig 경로 |
| Proxmox VE | 노드 CPU·메모리, VM·컨테이너 상태, 작업 진행 | 전원 작업, 앱 안 VM VNC 콘솔·컨테이너/노드 셸, 웹 화면. 계정 암호·API 토큰 인증 |
| IPMI (BMC) | 전원 상태·온도·전압·팬·전원 센서, 시스템 이벤트 로그·FRU 자산 정보 | 전원·리셋·식별 LED·다음 부팅 장치, SOL 시리얼 콘솔, 제조사 HTML5 KVM 웹 화면 연동 |

**강점:** 물리 서버 센서부터 VM·컨테이너·파드까지 다루고, 목록에서 확인한 대상을 바로 콘솔이나 셸로 열 수 있습니다. Docker·Kubernetes는 기존 SSH로 명령을 실행하므로 Portunus 전용 에이전트가 필요하지 않습니다.

Docker·kubectl 계열 명령과 권한은 대상 서버에 있어야 합니다. Kubernetes 사용량에는 metrics-server가 필요합니다. Proxmox 콘솔과 BMC 전원·KVM은 대상의 기능·계정 권한·펌웨어에 따라 이용 범위가 달라집니다.

## 6. DB 조회·변경·운영 점검

**데이터베이스 탐색**은 PostgreSQL·MySQL/MariaDB 서버와 SQLite 파일을 지원합니다.

- 테이블·뷰 탐색과 SQL 결과 표, NULL·이진 값 표시, CSV 저장.
- 기본 읽기 전용 모드와 **명령 실행·변경 허용** 모드.
- 변경 모드에서 DML·DDL·관리 명령·트랜잭션과 여러 SQL 실행, 문장 수·영향 행 수·마지막 결과 확인.
- 실행 전 대상·SQL 확인, 결과 행 수·시간·용량 제한, 서버 쿼리 중지.
- 활성 세션·잠금 대기·테이블 용량·무결성 등 DB별 운영 점검 SQL.
- TLS 인증서 검증·사용자 CA, 암호를 제외한 접속 프로필 보관. SQL·결과는 자동 저장하지 않음.
- 기존 SSH 포트 포워딩과 조합한 내부 DB 접근, AWS RDS에서 접속 정보 전달.

**강점:** 접속·조회에 이어 운영 점검과 변경 작업까지 같은 도구에서 다루되, 변경 허용 여부와 대상을 확인합니다. DB 계정의 서버 권한은 그대로 적용됩니다.

## 7. HTTP·URL·인증서와 로컬 유틸리티

| 도구 | 제공하는 작업 |
|---|---|
| HTTP 요청 | 메서드·URL·파라미터·헤더, JSON/텍스트/XML/폼 본문, Basic/Bearer 인증, 시간 제한·리디렉션·TLS 검증 설정 |
| 응답 분석 | 상태·소요 시간·첫 바이트·크기·헤더·본문·JSON 정렬, 인증서 발급자·SAN·유효 기간·리디렉션 경로 |
| 요청 재사용 | 기록·요청 저장, curl 복사, 응답 본문 파일 저장. 인증 값과 토큰·쿠키 헤더 값은 기록·저장 대상에서 제외 |
| URL 일괄 확인 | 최대 200개 URL의 상태·시간·최종 주소·서버·인증서 만료 확인, CSV 저장 |
| 엔지니어 유틸리티 | JSON 정렬/검증/압축, 한글 Base64·URL 인코딩, JWT 클레임·만료 시각, Unix 시간, 텍스트 SHA-256 |
| 설정 비교 | 붙여넣기·UTF-8 파일의 변경 전후 줄 비교, 추가/삭제·줄 번호·공백 무시·변경 줄 필터·보고서 저장 |

**강점:** 웹 장애 점검, API 호출 확인, 인증서 만료 확인, 설정 변경 검토를 함께 처리합니다. 변환 도구와 설정 비교 입력은 로컬에서 처리하고 자동 저장하지 않습니다. JWT 해석은 서명 검증 기능이 아닙니다. HTTP 요청은 이 PC에서 직접 전송하며 시스템 프록시는 사용하지 않습니다.

## 8. AWS를 UI에서 관리

목록·검색·세부 정보·점검·운영 작업은 **화면과 버튼**으로 사용합니다. AWS CLI는 앱 안에서 인증·API 통신을 담당합니다.

| 영역 | 제공하는 작업 |
|---|---|
| 인증 | IAM 키를 앱 금고에 암호화 등록, 기존 AWS CLI 프로필, Identity Center SSO 로그인, MFA·STS 임시 자격 증명·AssumeRole |
| 계정·리전 | 실제 호출 계정·사용자/역할 확인, 프로필·리전 선택 |
| EC2 | 목록·검색·상세, CPU·상태 검사, SSH/RDP 접속, 권한 사전 확인과 실행 확인을 거친 시작·중지·재부팅 |
| RDS | DB 인스턴스·Aurora 클러스터, 공개 접근·백업·암호화 점검, CPU·연결·저장 공간, DB 탐색기로 접속 정보 전달 |
| S3 | 버킷의 퍼블릭 차단·정책 공개·암호화·버전 관리·수명 주기 점검, 객체 폴더 탐색·다운로드·기간 제한 서명 URL |
| 네트워크 | VPC·서브넷·보안 그룹, 인터넷에 열린 관리·DB 포트 점검 |
| IAM 점검 | 계정 요약과 자격 증명 보고서를 통한 계정·자격 증명 상태 확인 |
| SSM | 조건을 갖춘 EC2의 Session Manager 셸을 터미널 탭으로 열기 |
| 결과 활용 | 리소스 목록 CSV, AWS 웹 콘솔로 열기 |

**강점:** **IAM Identity Center 없이 일반 IAM 키로도 사용할 수 있습니다.** 계정을 먼저 확인하고, 목록에서 원격 접속이나 DB 확인으로 이어갑니다. 운영 태그 EC2 전원 작업은 인스턴스 ID 재입력을 요구합니다.

AWS CLI v2와 필요한 IAM 권한이 있어야 합니다. SSM은 추가로 Session Manager 플러그인·대상 SSM Agent·인스턴스 역할·통신 경로가 필요합니다. 앱에 키를 넣는 것만으로 권한이나 서비스 설정이 생기지는 않습니다. IAM 키 프로필은 세션용 `.pbackup`에 포함되지 않습니다.

## 9. 내장 서버와 VPN 상태

| 도구 | 제공하는 작업 |
|---|---|
| SFTP 서버 | PC의 한 폴더를 SSH 암호화로 공유. 임시 계정·12자 이상 암호·시작마다 새 호스트 키/지문, 기본 읽기 전용·폴더 격리 |
| TFTP 서버 | 설정 파일·펌웨어 전송, blksize/tsize, 업로드 허용·덮어쓰기 선택, 루트 밖 경로 접근 차단 |
| Syslog 서버 | 장비 로그 실시간 수신, 등급·문자열 필터, 일별 파일 저장 |
| VPN 연결 상태 | GlobalProtect·FortiClient 등 설치된 클라이언트 검색·실행, VPN 어댑터 IP·게이트웨이·DNS 확인 |

**강점:** 파일 전달·장비 로그 수집에 필요한 서버를 작업 PC에서 열고, 현재 접속 환경을 함께 확인합니다. 상대 장비가 해당 프로토콜을 지원하고 작업 PC로 접근할 수 있어야 합니다.

VPN 인증·터널 연결은 공식 클라이언트가 담당합니다. Portunus는 VPN 직접 연결을 제공하지 않으며, 어댑터 활성 표시만으로 VPN 인증 성공을 확정하지 않습니다. TFTP는 프로토콜 자체에 암호화가 없습니다.

## 10. 접속 정보 보관·가져오기·내보내기

- **암호 금고:** 마스터 암호를 Argon2id로 처리하고 비밀을 AES-256-GCM으로 암호화. 세션별 저장 또는 매번 입력 선택.
- **저장 암호 일괄 변경:** 폴더·프로토콜·사용자 이름으로 대상을 골라 앱에 저장된 암호를 일괄 교체. 대상 장비의 계정 암호를 변경하는 기능은 아님.
- **기존 프로그램 이관:** mRemoteNG XML의 접속 정보·암호·상속, 이 PC PuTTY 레지스트리 세션 가져오기.
- **CSV·Excel:** `.csv`·`.xlsx`를 미리보기 후 새 폴더에 등록. Proxmox·SNMP·IPMI 등 지원 프로토콜과 기본 포트 적용. 가져온 암호는 금고에 암호화.
- **CSV 내보내기:** 암호를 제외한 접속 목록.
- **암호화 세션 백업:** 암호까지 포함하는 `.pbackup` 내보내기·가져오기. Argon2id + AES-256-GCM. 앱 전체 데이터 백업과는 구분.
- **연결 대상 확인:** SSH 호스트 키, Proxmox·BMC의 자체 서명 인증서 지문 확인·고정, DB TLS 검증.

**강점:** 정리해 둔 장비 목록을 옮겨 시작하고, 평문 계정 파일 대신 금고와 암호화 백업으로 보관할 수 있습니다. 가져오기 원본 CSV/Excel은 원래 파일이므로 자동으로 암호화되지 않습니다.

## 11. 환경 표시·디자인·업데이트

- **상단 PC 정보:** PC 이름·계정·사설 IP·넷마스크·게이트웨이·공인 IP·VPN 주소. 복사와 어댑터별 DNS·MAC·속도 상세.
- **표시 선택:** PC 정보 줄 또는 공인 IP 조회를 설정에서 끌 수 있어 발표·촬영·폐쇄망 환경에 맞춤.
- **14개 테마:** 어둡게·밝게·Nord·Dracula·Tokyo Night·Gruvbox·Solarized·Catppuccin·One Dark·Monokai·GitHub 밝게·고대비 계열.
- 강조색·화면 간격·패널/선 구분·화면 글꼴·터미널 글꼴 선택, 창 크기와 분할에 맞춘 배치.
- 설정을 화면·PC 정보·터미널·로그/파일·외부 도구·금고·정보·업데이트로 분리.
- **외부 도구 준비:** 설치 여부 확인과 공식 설치 파일 실행, AWS CLI·SSM 플러그인 준비.
- **서명 검증 업데이트:** 시작 시와 6시간마다 새 릴리스 확인, 설치·재시작 전 확인, 업데이트 서명 검증, 설치 전 DB 백업.
